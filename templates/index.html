Download and upload are estimated from bytes transferred divided by elapsed time. Response time is browser-to-server HTTP latency, not ICMP ping. Server capacity, hosting location, routing, Wi-Fi quality, and device load can affect results.

Testing transfers data. This Vercel starter uses 4 MiB transfers to stay below the function payload limit. These short transfers can be inaccurate on fast connections. Avoid running repeated tests unnecessarily.
